# Ablescribe - Releases

This repository holds nothing but the built Windows installer for each
released version of Ablescribe (called Snip Happens up to version 1.3.223).
There is no source code here - the app itself lives in a separate, private
repository.

Installed copies of Ablescribe, and of Snip Happens before it, check here
automatically for updates.

Written with the help of an AI coding assistant. Designed, directed and checked by Ross O'Leary.
